题目背景：认识“一带一路”

“一带一路”倡议覆盖区域广阔、各国发展阶段差异大，是学习多准则综合评估的理想场景。了解背景，有助于你选择国家、给准则打分，并写出更有说服力的分析报告。

什么是“一带一路”倡议

“一带一路”是“丝绸之路经济带”和“21 世纪海上丝绸之路”的简称，于 2013 年提出。它以共商、共建、共享为原则，重点推动“五通”：政策沟通、设施联通、贸易畅通、资金融通、民心相通。

覆盖范围与区域特色

沿线涵盖东南亚、南亚、中亚、西亚、中东欧、东非等区域，既有新兴市场，也有转型经济体。各国在资源禀赋、地理区位、发展阶段上差异显著，这正是需要多准则比较的原因。

AHP 知识速查

课堂核心内容汇总，随时回来翻

1. AHP 基本思想

把复杂的多准则决策分解为“目标—准则—方案”的层次，通过同一层因素之间的两两比较得到相对重要性，进而合成权重并排序。它把主观判断转化为可计算的数值，同时用一致性检验约束判断的合理性。

2. 层次结构

  • 目标层：决策的总目标（本作业：投资适宜程度排序）；
  • 准则层：影响目标的因素（本作业：七项评估因素）；
  • 方案层：待比较的备选对象（本作业：沿线国家）。

3. 1–9 标度

标度 aij含义（i 相对 j）
1两者同等重要
3i 比 j 稍微重要
5i 比 j 明显重要
7i 比 j 强烈重要
9i 比 j 极端重要
2,4,6,8相邻判断的中间值
倒数j 相对 i 的重要程度

4. 判断矩阵

n 个准则构成 n×n 矩阵 A，满足：aii=1，aij>0，且 aji=1/aij。因此只需填写上三角即可。

A = [aij]，aij = wi / wj（理想情况下）

5. 一致性检验

CI = (λmax − n) / (n − 1)，　CR = CI / RI

当 CR < 0.1 时，认为判断矩阵通过一致性检验；否则需调整判断。RI 为随机一致性指标：

n12345678910
RI000.580.901.121.241.321.411.451.49

6. 层次单排序

先用判断矩阵求各准则权重，再分别看每个方案在同一准则下的相对表现。

wi = (∏j aij)1/n ／ Σk(∏j akj)1/n

正向准则：rik = (xik − min) / (max − min)；逆向准则反向处理。得到各国在每项准则下的单排序得分。

7. 层次总排序

把准则权重与单排序得分合成，得到方案的总排序。

Sk = Σi wi × rik

总得分越高，投资适宜程度越高。

8. 常见误区

  • 判断矩阵未按“行相对列”填写，导致上下三角不互为倒数；
  • CR 超过 0.1 却不调整判断，直接使用结果；
  • 混淆正向与逆向指标，未对“经济风险”反向处理；
  • 只用绝对分数，没有体现 AHP 两两比较的核心思想。
